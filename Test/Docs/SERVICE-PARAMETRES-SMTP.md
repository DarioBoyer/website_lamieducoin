# 📧 Service de Gestion des Paramètres SMTP

## 📋 Vue d'ensemble

Service de gestion des paramètres système pour la configuration SMTP avec **chiffrement des données sensibles** (compte et mot de passe).

## 🗄️ Structure de la base de données

### Table `Parameters`
```sql
create table public."Parameters" (
  id bigint generated by default as identity not null,
  "LastUpdated" timestamp with time zone not null default now(),
  smtp character varying null,
  port smallint null,
  smtp_account character varying null,      -- ⚠️ CHIFFRÉ
  smtp_password character varying null,     -- ⚠️ CHIFFRÉ
  constraint Parameters_pkey primary key (id)
);
```

**Note importante**: Les champs `smtp_account` et `smtp_password` sont stockés **chiffrés** dans la base de données.

## 🔐 Sécurité et chiffrement

### Algorithme utilisé
- **XOR** avec une clé secrète
- **Base64** pour l'encodage
- Chiffrement symétrique simple

### Clé de chiffrement
```javascript
this.encryptionKey = 'LaMieDuCoin2025SecretKey';
```

⚠️ **Important pour la production:**
- Utiliser une vraie librairie de chiffrement (ex: crypto-js, bcrypt)
- Stocker la clé dans une variable d'environnement
- Utiliser un algorithme plus robuste (AES-256, etc.)

### Exemple de chiffrement
```javascript
// Original
smtp_account: "lamieducoin@gmail.com"
smtp_password: "MonMotDePasse123!"

// Chiffré (stocké dans Supabase)
smtp_account: "PB4cHR0eGxwbHhsfHB0="
smtp_password: "QB8fGhscHR4dHxweHR8eGx=="
```

## 🚀 Utilisation du service

### Import et initialisation
```javascript
import dbConnection from '../data/js/config/database.js';
import parametersService from '../data/js/services/parametersService.js';

// Initialiser la connexion
await dbConnection.init();
```

### Récupérer les paramètres
```javascript
// Récupère et déchiffre automatiquement
const params = await parametersService.getParameters();

console.log(params);
// {
//   id: 1,
//   lastUpdated: "2025-11-02T...",
//   smtp: "smtp.gmail.com",
//   port: 587,
//   smtp_account: "lamieducoin@gmail.com",  // Déchiffré
//   smtp_password: "MonMotDePasse123!"      // Déchiffré
// }
```

### Vérifier si configuré
```javascript
const isConfigured = await parametersService.isSmtpConfigured();

if (!isConfigured) {
    // Afficher le formulaire de configuration
}
```

### Obtenir la configuration SMTP
```javascript
const config = await parametersService.getSmtpConfig();

// {
//   smtp: "smtp.gmail.com",
//   port: 587,
//   account: "lamieducoin@gmail.com",
//   password: "MonMotDePasse123!"
// }
```

### Mettre à jour les paramètres
```javascript
const newConfig = {
    smtp: 'smtp.gmail.com',
    port: 587,
    smtp_account: 'contact@lamieducoin.ca',
    smtp_password: 'NouveauMotDePasse!'
};

await parametersService.updateSmtpParameters(newConfig);
// Les données sensibles sont automatiquement chiffrées
```

### Tester la connexion SMTP
```javascript
const success = await parametersService.testSmtpConnection();

if (success) {
    console.log('✅ Connexion SMTP réussie');
} else {
    console.log('❌ Échec de la connexion SMTP');
}
```

## 🔧 API du service

### Méthodes principales

#### `getParameters()`
Récupère les paramètres depuis Supabase (déchiffrés automatiquement)
```javascript
const params = await parametersService.getParameters();
```

#### `isSmtpConfigured()`
Vérifie si tous les paramètres SMTP sont configurés
```javascript
const configured = await parametersService.isSmtpConfigured();
```

#### `getSmtpConfig()`
Obtient la configuration SMTP déchiffrée
```javascript
const config = await parametersService.getSmtpConfig();
```

#### `updateSmtpParameters(config)`
Met à jour les paramètres SMTP (chiffre automatiquement)
```javascript
await parametersService.updateSmtpParameters({
    smtp: 'smtp.office365.com',
    port: 587,
    smtp_account: 'admin@lamieducoin.ca',
    smtp_password: 'SecretPassword123!'
});
```

#### `testSmtpConnection()`
Teste la connexion SMTP (simulation pour le moment)
```javascript
const success = await parametersService.testSmtpConnection();
```

### Méthodes de chiffrement

#### `encrypt(text)`
Chiffre un texte
```javascript
const encrypted = parametersService.encrypt('MonMotDePasse');
```

#### `decrypt(encryptedText)`
Déchiffre un texte
```javascript
const decrypted = parametersService.decrypt('PB4cHR0eGxwbHhsfHB0=');
```

## ⚠️ Notes importantes

### Sécurité
1. **Ne jamais afficher les mots de passe en clair** dans les logs
2. **Utiliser HTTPS** en production
3. **Améliorer le chiffrement** pour la production (AES-256, etc.)
4. **Stocker la clé de chiffrement** dans une variable d'environnement
5. **Valider les entrées** utilisateur

### Limitations actuelles
- Chiffrement simple (XOR + Base64)
- Test de connexion SMTP en simulation
- Une seule configuration SMTP supportée
- Clé de chiffrement codée en dur
