# 🚀 Guide de démarrage rapide - Configuration SMTP

## ⚡ En 3 étapes simples

### 1️⃣ Créer la table dans Supabase

Aller dans Supabase > SQL Editor et exécuter:

```sql
create table public."Parameters" (
  id bigint generated by default as identity not null,
  "LastUpdated" timestamp with time zone not null default now(),
  smtp character varying null,
  port smallint null,
  smtp_account character varying null,
  smtp_password character varying null,
  constraint Parameters_pkey primary key (id)
) TABLESPACE pg_default;
```

### 2️⃣ Ouvrir la page de configuration

```
http://localhost:8000/pagesadmin/smtp-config.html
```

### 3️⃣ Remplir le formulaire

**Exemple avec Gmail:**
```
Serveur SMTP: smtp.gmail.com
Port: 587
Compte: votre-email@gmail.com
Mot de passe: votre-mot-de-passe-application
```

**Exemple avec Outlook/Office365:**
```
Serveur SMTP: smtp.office365.com
Port: 587
Compte: votre-email@outlook.com
Mot de passe: votre-mot-de-passe
```

Cliquer sur **"Enregistrer la configuration"**

## ✅ C'est fait !

- ✅ Enregistrées dans Supabase
- 🔐 Compte et mot de passe **chiffrés**

## 🔐 Gmail - Créer un mot de passe d'application

1. Aller sur https://myaccount.google.com/security
2. Activer la **vérification en 2 étapes** (si pas déjà fait)
3. Rechercher **"Mots de passe des applications"**
4. Créer un nouveau mot de passe pour "Mail"
5. Utiliser ce mot de passe de 16 caractères dans le formulaire

## 🐛 Dépannage rapide

### Problème: "Configuration requise"
**Solution**: Remplir tous les champs du formulaire

### Problème: "Erreur lors de l'enregistrement"
**Solutions**:
- Vérifier que la table `Parameters` existe dans Supabase
- Vérifier la connexion à Supabase
- Vérifier les permissions de la table

## 🎯 Prochaines étapes

Après la configuration SMTP, vous pouvez:

1. **Utiliser la config dans votre code**
   ```javascript
   const config = await parametersService.getSmtpConfig();
   // Utiliser avec nodemailer ou autre
   ```

2. **Envoyer des emails de confirmation de commande**
   ```javascript
   // Exemple avec nodemailer (à implémenter)
   const transporter = nodemailer.createTransport({
       host: config.smtp,
       port: config.port,
       auth: {
           user: config.account,
           pass: config.password
       }
   });
   ```

3. **Notifications automatiques**
   - Confirmation de commande
   - Statut de production
   - Alerte de livraison
