## 📱 Responsive Design

### Breakpoints
- ✅ **5 breakpoints** définis :
  - Desktop large : > 1200px
  - Desktop : 992px - 1200px
  - Tablette : 768px - 992px
  - Mobile : 576px - 768px
  - Petit mobile : < 576px

### Adaptations
- ✅ **Navigation** :
  - Desktop : tous les onglets visibles
  - Tablette : scrollable si nécessaire
  - Mobile : scrollable horizontal
- ✅ **Grilles** :
  - 4 cols → 2 cols → 1 col (statistiques)
  - 3 cols → 2 cols → 1 col (catégories)
- ✅ **Tailles de police** :
  - clamp() pour adaptation fluide
  - Lisibilité sur tous les écrans
- ✅ **Espacements** :
  - Padding réduit sur mobile
  - Marges adaptées
  - Zones de clic ≥ 44x44px
