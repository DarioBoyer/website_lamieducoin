## 🔧 États interactifs

### Hover (survol)
```
Normal:     ┌──────────┐
            │ Bouton   │
            └──────────┘

Hover:      ┌──────────┐
            │ Bouton ▲ │  (translateY: -8px)
            └──────────┘
            └────────────┘ (shadow augmentée)
```

### Focus (clavier)
```
Normal:     [Input field]

Focus:      ┌─────────────────┐
            │ Input field  ▲  │  (border colorée)
            └─────────────────┘
                 └──┘ (shadow colorée)
```

### Active (sélection)
```
Normal:     ○ Option

Active:     ● Option ◄  (background coloré)
```
