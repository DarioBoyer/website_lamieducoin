## 📱 Compatibilité et Responsive

### Appareils supportés
- ✅ **Desktop** : 1920x1080 et plus (4 colonnes)
- ✅ **Tablette** : 768x1024 (2 colonnes, navigation scrollable)
- ✅ **Mobile** : 375x667 et plus (1 colonne, touch-friendly)
- ✅ **Tous navigateurs modernes** : Chrome, Firefox, Edge, Safari

### Breakpoints
```css
/* Desktop large */   > 1200px
/* Desktop */         992px - 1200px
/* Tablette */        768px - 992px
/* Mobile */          576px - 768px
/* Petit mobile */    < 576px
```

### Accessibilité
- ✅ **WCAG AA** : Contraste 4.5:1 minimum
- ✅ **Navigation clavier** : Tab, Enter, Escape
- ✅ **Lecteurs d'écran** : ARIA, role, visually-hidden
- ✅ **Zones cliquables** : Minimum 44x44px

## 🚀 Démarrage Rapide

### Méthode 1 : Serveur local (Recommandé)
```powershell
# Ouvrir un terminal PowerShell
cd "chemin/vers/Livre"

# Démarrer un serveur Python
python -m http.server 8080

# Ouvrir dans le navigateur
Start-Process "http://localhost:8080/index.html"
```

### Méthode 2 : Ouvrir directement
Double-cliquez sur `index.html` (fonctionnalités limitées sans serveur)

### Navigation
1. Page d'accueil affiche 4 statistiques + 6 catégories
2. Cliquez sur un onglet pour changer de section
3. Utilisez la recherche pour trouver une recette
4. Cliquez sur une catégorie puis une recette
5. La recette s'affiche dans l'iframe à droite
