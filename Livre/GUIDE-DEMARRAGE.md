## 🎯 Conseils d'utilisation

### Pour une expérience optimale :

1. **Utilisez un navigateur moderne**
   - Chrome 90+
   - Firefox 88+
   - Edge 90+
   - Safari 14+

2. **Résolution recommandée**
   - Desktop : 1920x1080 ou plus
   - Tablette : 768x1024 ou plus
   - Mobile : 375x667 ou plus

3. **Navigation fluide**
   - Utilisez les onglets pour changer de section
   - Utilisez la recherche pour trouver rapidement
   - Cliquez sur les catégories pour filtrer

4. **Affichage des recettes**
   - Attendez le chargement complet (spinner)
   - Faites défiler dans l'iframe
   - Utilisez le zoom du navigateur si besoin (Ctrl + / Ctrl -)

## 🐛 Dépannage

### Le site ne s'affiche pas correctement
1. Vider le cache du navigateur (Ctrl + F5)
2. Vérifier que JavaScript est activé
3. Essayer un autre navigateur

### Les recettes ne se chargent pas
1. Vérifier que le serveur est démarré
2. Vérifier les chemins des fichiers
3. Ouvrir la console développeur (F12) pour voir les erreurs

### La recherche ne fonctionne pas
1. Vérifier que JavaScript est activé
2. Rafraîchir la page
3. Essayer avec un autre terme de recherche

### Problèmes de responsive
1. Vérifier le zoom du navigateur (doit être à 100%)
2. Rafraîchir la page
3. Tester en mode navigation privée
